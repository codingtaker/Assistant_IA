# Roadmap

## v2.0 — MVP (current)

- [x] AI pitch generation with real LLMs (OpenAI + Anthropic)
- [x] 4 templates: Lean Canvas, Elevator Pitch, Investor Pitch, Executive Summary
- [x] Multi-provider abstraction with fallback
- [x] EN / FR bilingual interface
- [x] Export: TXT, PDF, JSON
- [x] Pitch history (localStorage)
- [x] Rate limiting & security (Helmet, CORS)
- [x] Open-source documentation
